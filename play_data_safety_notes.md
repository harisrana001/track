# Google Play Data Safety Form Guide for Trace (Draft)

> **DISCLAIMER**: This document is a draft reference guide for preparing Google Play Console Data Safety questionnaire declarations. It does not constitute legal advice. Developers should verify all declarations against Google Play's latest Data Safety policy and current Firebase documentation before submitting their app release.

*Configuration Target: Trace with Optional, Opt-In Anonymous Firebase Analytics*

---

## 1. Overview Summary

| Question | Recommended Answer | Rationale |
| :--- | :--- | :--- |
| **Does your app collect or share any user data?** | **Yes** | Even though data is anonymous and opt-in, Firebase Analytics collects pseudonymized app interactions and Firebase instance IDs when the user gives consent. |
| **Is all user data collected by your app encrypted in transit?** | **Yes** | Firebase Analytics transmits all telemetry over HTTPS using Transport Layer Security (TLS). |
| **Do you provide a way for users to request data deletion?** | **Yes** | Users can opt out anytime in Settings, clear app storage, or uninstall the app. |
| **Is data collection optional?** | **Yes** | Analytics collection is OFF by default. Data is only collected if the user explicitly consents. |
| **Is data sold to third parties?** | **No** | Data is never sold, brokered, or exchanged for monetary consideration. |

---

## 2. Detailed Data Type Declarations

### A. App Activity / App Interactions
- **Data Type**: **App interactions**
- **Collected**: **Yes** (Only when user opts in)
- **Shared**: **No** (Processed by Firebase as a service provider on behalf of the developer; not shared with external third parties)
- **Purposes**:
  - **Analytics**: To assess puzzle difficulty, drop-off rates, and level progression.
- **Is this data optional?**: **Yes** (User can choose whether to share anonymous usage data).
- **Specific Events**: `tutorial_complete`, `level_start`, `level_complete`, `level_exit`, `pack_reached`, `hint_used`, `share_tapped`, `start_choice`.

### B. Device or Other Identifiers
- **Data Type**: **Device or other IDs**
- **Collected**: **Yes** (Firebase Installation ID / App Instance ID generated by Firebase SDK)
- **Shared**: **No**
- **Purposes**:
  - **Analytics**: To measure unique sessions and calculate aggregate retention (Day 1, Day 7).
- **Is this data optional?**: **Yes** (Deactivated by default; only initiated upon user opt-in).
- **Advertising ID (AD_ID)**: **NOT COLLECTED**. The native `AndroidManifest.xml` explicitly sets:
  ```xml
  <meta-data android:name="google_analytics_adid_collection_enabled" android:value="false" />
  <meta-data android:name="google_analytics_default_allow_ad_personalization_signals" android:value="false" />
  ```
  Therefore, the Google Play declaration for Advertising ID should be marked as **Not Collected**.

## 3. Data Safety Checklist Summary

| Form Question / Category | Value to Select |
| :--- | :--- |
| **Data Collection** | |
| - Location | Not collected |
| - Personal info (name, email, phone) | Not collected |
| - Financial info | Not collected |
| - Health & fitness | Not collected |
| - Messages / Photos / Audio | Not collected |
| - Files and docs | Not collected |
| - App activity -> App interactions | **Collected (Optional, for Analytics)** |
| - App activity -> In-app search history | Not collected |
| - App activity -> Installed apps | Not collected |
| - App activity -> Other actions | Not collected |
| - Web browsing | Not collected |
| - App info and performance | **Diagnostics / Performance (if crash SDK enabled)** |
| - Device or other IDs -> Device or other IDs | **Collected (Optional, for Analytics - Instance ID)** |
| **Security Practices** | |
| - Data encrypted in transit? | **Yes** (TLS) |
| - User can request data deletion? | **Yes** (Toggle opt-out in Settings or wipe app data) |
| - Committed to Child Directed Treatment? | Ensure COPPA settings in Google Play Console match target audience |

## 4. Verification Against Current Firebase Documentation

Prior to app submission, review Google's official documentation on Firebase Analytics data safety declarations:
- [Google Play Data Safety guidance for Firebase Analytics](https://firebase.google.com/docs/analytics/data-safety)
- Verify that no other SDKs (e.g. ad networks) collect data outside what is listed here.
